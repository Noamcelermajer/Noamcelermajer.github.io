# Pocket Files 1.0

[Download the Android APK](https://raw.githubusercontent.com/Noamcelermajer/Noamcelermajer.github.io/main/downloads/pocket-files/Pocket-Files-1.0.apk)

Browse files, split and join large files, and compress or extract ZIP archives. Offline, with no ads or analytics.

- Android 8.0+; target Android 16/API 36.
- Custom split sizes and SHA-256 verified joining using the included parts manifest.
- Background progress and cancellation.
- ZIP only; no RAR, 7z, encrypted ZIP or .z01 volumes.
- 83 file-engine assertions passed. Signature verified. Not yet tested on a physical phone or emulator.

Install the APK, choose Browse folder or Select files, select items, choose an operation, and choose an output folder.
